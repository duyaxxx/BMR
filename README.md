作者：KanoNoUta, COXOIDA

本仓库仅发布编译后的插件、运行时配置和许可证，不包含项目源码、调试符号或源码仓库历史。

## 卫月安装

在卫月插件安装器的设置中，打开「实验性」，将下方地址加入「第三方插件仓库」，保存并刷新插件列表，然后搜索 Bossmod Reborn。

https://raw.githubusercontent.com/duyaxxx/BMR/main/repo.json
